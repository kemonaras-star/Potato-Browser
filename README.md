### 🚀 Why Potato Browser?
Modern browsers consume gigabytes of RAM just to open a single tab. **Potato Browser** is built from the ground up to run smoothly on ultra-low-spec computers with minimal memory and CPU usage.

### ✨ Key Features
* **🥔 Potato Mode:** Automatically blocks heavy images, videos, and animations to save RAM and speed up page loading.
* **🌙 Built-in Dark Mode:** Applies a comfortable dark theme across pages to protect your eyes.
* **🛡️ Automatic Ad-Blocker:** Removes sponsored links and annoying ad banners out of the box.
* **🧭 Minimalist Navigation:** Clean address/search bar with quick navigation buttons (`Back`, `Forward`, `Reload`, `Home`).

---

### ⌨️ Keyboard Shortcuts

| Shortcut | Action |
| :--- | :--- |
| **`Ctrl + X`** or **`F1`** | Open / Close Settings (Toggle Potato Mode & Dark Mode) |
| **`Esc`** | Return immediately to the clean Home screen |

### 📥 How to Install & Run
1. Click the green **Download** button above (or go to [Releases](https://github.com)).
2. Download **`PotatoBrowser-v1.0-Win64.zip`** and extract it anywhere.
3. Double-click **`PotatoBrowser.exe`** to launch (no installation required).
> **Note:** If Windows SmartScreen shows a warning because the app is new, click **More info** -> **Run anyway**.
